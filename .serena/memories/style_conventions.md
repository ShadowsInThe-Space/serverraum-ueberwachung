# Style & Konventionen

## Benennung
- **C++ (Firmware):** `PascalCase` für Klassen, `camelCase` für Methoden und Variablen.
- **Python (Backend):** `snake_case` (PEP 8), Type Hints, Docstrings.
- **JavaScript (Frontend):** `camelCase` (ES6+ Module).
- **SQL:** `UPPER CASE` für Keywords, `snake_case` für Tabellen/Spalten.

## Code-Qualität
- **Sprache:** Kommentare auf Deutsch (IHK-Anforderung), Namen selbsterklärend auf Deutsch.
- **SOLID:** Prinzipien beachten.
- **ORM/DB:** SQL-Standards einhalten.
- **Dokumentation:** Doxygen-Stil für C++, Docstrings für Python.

## Git
- **Commits:** Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`).
- **Worktrees:** Bevorzugtes System für Feature-Arbeit/Bugfixes.
