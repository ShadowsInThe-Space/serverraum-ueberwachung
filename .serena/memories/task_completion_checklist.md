# Checkliste für Aufgabenabschluss

1. **Linting & Formatting:** Sicherstellen, dass der Code den Konventionen entspricht.
2. **Kommentare:** Deutsche Kommentare für IHK-Prüfer vorhanden?
3. **Tests:** Funktion im Browser (Chrome MCP) oder via Unit-Tests verifiziert?
4. **Git:** Änderungen in einem sauberen Branch/Worktree committet?
5. **Dokumentation:** `AGENTS.md` oder `README.md` bei Bedarf aktualisiert?
6. **Task-Tracker:** Notion-Status aktualisiert?
